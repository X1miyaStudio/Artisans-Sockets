# Artisan's Sockets

Artisan's Sockets adds lightweight Vanilla+ equipment customization. Combine a tool, weapon, or armor piece with a gemstone on an anvil to apply one permanent specialized bonus.

## Socketing

1. Drop a supported item on top of an anvil.
2. Drop quartz, an amethyst shard, a diamond, an emerald, or lapis lazuli beside it.
3. The gem is consumed and the equipment receives its socket effect.

| Gem | Tools and weapons | Armor |
| --- | --- | --- |
| Quartz | Auto-smelting | Toughness and knockback resistance |
| Amethyst | Movement speed | Movement speed |
| Diamond | Attack damage and mining efficiency | Max health and toughness |
| Emerald | Block and entity reach | Safe-fall distance and step height |
| Lapis | Mining and underwater efficiency | Oxygen and underwater mining |

## Installation

Place the ZIP in `<world>/datapacks/`, then run `/reload`.
